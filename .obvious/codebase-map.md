# Mantua-v1 — codebase map (folder level, depth 2)

| Path                                  | What lives there                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/`                                   | Root workspace: `package.json` (workspaces + shared scripts), `package-lock.json`, `eslint.config.js`, `.prettierrc.json`, `.husky/` (pre-commit lint-staged, pre-push typecheck), `vercel.json` (Vercel deploy + crons), `skills-lock.json`, `Mantua Prototype.html` (early design source)                                                                                         |
| `agent/`                              | Base Mainnet agent runtime: `src/action-providers/` (viem action kit), `src/config/` (zod env), `src/lib/`, `src/abis/`; isolated workspace pinning zod v3 + viem                                                                                                                                                                                                                   |
| `api/`                                | Vercel serverless entry (`index.ts`) — reuses `server/src/app.ts` wiring                                                                                                                                                                                                                                                                                                            |
| `assets/`                             | App logos (light/dark)                                                                                                                                                                                                                                                                                                                                                              |
| `client/`                             | Vite + React SPA: `src/features/` (markets, agent, swap, liquidity, portfolio, analyze), `src/components/` (shell, landing, legal, docs), `src/lib/` (privy config/provider, chains, tokens, chat-intent), `src/hooks/`; `vite.config.ts` (port 5173 strictPort, `/api` proxy → :3001)                                                                                              |
| `client/src/db` → see `server/src/db` | (Drizzle schema lives server-side; client never touches the DB)                                                                                                                                                                                                                                                                                                                     |
| `contracts/`                          | Foundry workspace: `src/hooks/dynamic-market/` (8 Solidity modules), `src/markets/` (MarketFactory, Market, OutcomeToken, Resolver), `test/` (full-lifecycle E2E, invariants), `script/` (deploy + `verify-hooks.ts`); `hooks/stable-protection` + `hooks/dynamic-fee` are git submodules; `lib/` deps NOT vendored (gitignored)                                                    |
| `deploy/`                             | Foundry deploy scripts + per-chain deployment records (hook periphery, pool setup, escrow)                                                                                                                                                                                                                                                                                          |
| `docs/`                               | `architecture.md` (living notes + decision log), `specs/` (market lifecycle, market-id, hook spec), `decisions/`, `tasks/` (roadmaps), `security/` (sign-off, deployment checklists), `ops/` (incident runbook), `legal/`, `x402-setup.md`                                                                                                                                          |
| `landing/`                            | Landing-page design variants (`v1`–`v4` JSX mockups + static HTML)                                                                                                                                                                                                                                                                                                                  |
| `scripts/`                            | `build-server.mjs` — esbuild bundle of the server for the Vercel function                                                                                                                                                                                                                                                                                                           |
| `server/`                             | Express API: `src/routes/` (44 route files — agent, markets, pools, swaps, crons, x402), `src/lib/` (v4-contracts, markets-contracts, sports/espn, agent loop, circle kits, defillama, basescan), `src/db/` (Drizzle schema + client), `src/middleware/` (auth, kill-switch, rate-limit), `drizzle/migrations/` (0000–0009), `dcw-entry.mjs` / `ubk-entry.mjs` (serverless entries) |
| `src/`                                | Legacy prototype shell (`app.jsx`, `panels.jsx`, …) — superseded by `client/`                                                                                                                                                                                                                                                                                                       |
